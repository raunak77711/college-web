# Week 6 — Workshop 6 of Class

This is Workshop 6 of class: a personal portfolio website built with plain HTML, CSS and JavaScript.

## Pages

- `index.html` — Home page with hero section, quick stats and info cards
- `about.html` — About page
- `contact.html` — Contact page

## Files

- `style.css` — All styling, including the light/dark theme
- `script.js` — Theme toggle, mobile menu and scroll reveal
- `images/` — Images used on the site

## How to run

Open `index.html` in a web browser.
